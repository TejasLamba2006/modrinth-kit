# user.projects

List projects owned by or shared with a user (defaults to the token's user)

| | |
|---|---|
| Tier | `read` |
| CLI | `modrinth user projects <user>` |
| MCP tool | `user_projects` |

## Input

| Field | CLI flag | Type | Required | Description |
|---|---|---|---|---|
| `user` | `--user` | string |  | User ID or username; omit for yourself |
