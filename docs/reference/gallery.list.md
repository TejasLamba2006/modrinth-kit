# gallery.list

List a project's gallery images (url identifies an image for update/delete)

| | |
|---|---|
| Tier | `read` |
| CLI | `modrinth gallery list <project>` |
| MCP tool | `gallery_list` |

## Input

| Field | CLI flag | Type | Required | Description |
|---|---|---|---|---|
| `project` | `--project` | string | yes | Project ID or slug |
