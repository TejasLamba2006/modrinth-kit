# collection.list

List a user's collections (v3 API)

| | |
|---|---|
| Tier | `read` |
| CLI | `modrinth collection list <user>` |
| MCP tool | `collection_list` |
| Token scope | `COLLECTION_READ` |

## Input

| Field | CLI flag | Type | Required | Description |
|---|---|---|---|---|
| `user` | `--user` | string |  | User ID or username; omit for yourself |
