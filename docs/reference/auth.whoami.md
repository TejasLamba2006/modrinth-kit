# auth.whoami

Return the user the current token belongs to

Use this first to verify a token works. Fails with code `auth` if no/invalid token.

| | |
|---|---|
| Tier | `read` |
| CLI | `modrinth auth whoami` |
| MCP tool | `auth_whoami` |
