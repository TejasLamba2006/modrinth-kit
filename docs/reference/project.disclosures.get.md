# project.disclosures.get

Get a project's content disclosures (AI use, telemetry, ads, paid features...) (v3 API)

| | |
|---|---|
| Tier | `read` |
| CLI | `modrinth project disclosures get <project>` |
| MCP tool | `project_disclosures_get` |
| Token scope | `PROJECT_READ` |

## Input

| Field | CLI flag | Type | Required | Description |
|---|---|---|---|---|
| `project` | `--project` | string | yes | Project ID or slug |
