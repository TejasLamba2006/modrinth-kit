# org.icon.set

Upload an organization icon (v3 API)

| | |
|---|---|
| Tier | `write` |
| CLI | `modrinth org icon set <org> <file>` |
| MCP tool | `org_icon_set` |
| Token scope | `ORGANIZATION_WRITE` |

## Input

| Field | CLI flag | Type | Required | Description |
|---|---|---|---|---|
| `org` | `--org` | string | yes | Organization ID or slug |
| `file` | `--file` | string | yes |  |
