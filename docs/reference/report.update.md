# report.update

Edit the body of your report, or close it

| | |
|---|---|
| Tier | `write` |
| CLI | `modrinth report update <id>` |
| MCP tool | `report_update` |
| Token scope | `REPORT_WRITE` |

## Input

| Field | CLI flag | Type | Required | Description |
|---|---|---|---|---|
| `id` | `--id` | string | yes |  |
| `body` | `--body` | string |  |  |
| `closed` | `--closed` | boolean |  |  |
